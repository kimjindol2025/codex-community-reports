### OpenAI Agents API: 시간 인식과 비동기 입력 (2026-11-20)

공식 예제에서 실험적 시간 인식과 비동기 함수 도구를 사용해 답변 대기 중에도 에이전트가 작업을 이어갈 수 있다.

- 중요성: 총괄 AI가 외부 입력 대기 중 멈추지 않는 설계에 참고.
- 적용 위치: JARVIS Orchestrator의 대기 상태 및 이벤트 입력 계약
- 주의: Agents API 접근 필요, 실험적 시간 인식. 현재 ChatGPT 대화의 자동 재개나 자체 서버 Codex 연속 실행을 보장하지 않는다.
- 출처: https://developers.openai.com/blog/time-awareness-and-async-input-for-personal-agents

### OpenAI Codex 운영 모니터링 설계 (2026-11-24)

운영 경보를 기점으로 읽기 전용 관측 자료를 조사하고 근거 기반 변경안을 제안하며 사람 승인 후 복구를 검증하는 공식 예제.

- 중요성: 실행 에이전트와 독립 검수 에이전트의 역할 및 승인 경계를 명확히 할 수 있다.
- 적용 위치: JARVIS 이벤트 수신·검수·운영 변경 승인
- 주의: 가이드이지 현재 자동 실행 기능의 구현 증거가 아니다. 운영 변경 권한은 별도 승인.
- 출처: https://developers.openai.com/blog/production-monitoring-with-codex
