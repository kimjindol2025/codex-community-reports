## 1. JARVIS 외부 레이더 — 적용 검토 가치가 있는 변경 1건

### OpenAI Agents SDK v1.0.0-alpha.1 — 2026-11-21 05:51 KST
- 공식 배포: https://github.com/openai/openai-agents-python/releases/tag/v1.0.0-alpha.1
- 변화: Python Agents SDK에 선택형 `CodexProvider`가 처음 추가됨. `RunConfig(model_provider=provider)`로 실행마다 선택하며, 배포 휠에 Codex Core를 내장해 별도 `codex app-server` 프로세스/JSON-RPC 없이 SDK 내부 호출을 지원.
- 왜 중요한가: BIGWASH JARVIS의 Codex/Agent Worker 호출 경로를 설계할 때 별도 app-server 브리지와 직접 SDK 경로를 비교할 후보가 생김. 현재 운영 구조가 Python Agents SDK를 실제로 사용하는지는 **UNVERIFIED**.
- 적용 위치: 향후 JARVIS Worker의 Codex 어댑터 설계 검토. **현재 Hello World DNS 차단 해결책은 아님.**
- 위험/이관: **프리릴리스 알파**. Python CPython 3.10–3.14 및 배포 아키텍처 제약. 이전 `0.24.0-alpha.8`의 `SessionState`와 새 `RunState` 형식은 호환되지 않으며 `Agent.run()`/`Session.submit()` 흐름은 `Runner.run()` 계열로 변경. 인증·승인·샌드박스·추적 정책을 격리환경에서 검증할 때까지 운영 도입 보류.
- 확인 출처: https://github.com/openai/openai-agents-python/releases/tag/v1.0.0-alpha.1 및 https://github.com/openai/openai-agents-python/blob/87e8f533c3b457fe632a5eb38ac42590d7f4d9fc/docs/models/codex.md (공식 GitHub Releases API로 게시 UTC 타임스탬프 직접 확인).

기타 공식 GitHub Releases API 상위 배포 확인: LiveKit Agents, LangGraph, Pipecat, Home Assistant Core, MCP Reference Servers, Leon. 이전 기록 이후 이 조사 범위에서 추가로 보고할 중요 릴리스 없음. LiveKit Wake Word 개별 커밋/전수 보안 권고와 제품 환경의 설치 버전은 미확인.
